## 🌟 Featured Projects

### 🤖 RAG PDF Chatbot — Conversational AI over Documents
A conversational **Retrieval-Augmented Generation (RAG)** application that lets users chat with their PDF documents and get accurate, context-grounded answers.

- 📄 Ingests PDFs, splits them into chunks and converts them into **embeddings**
- 🔍 Stores vectors in a **vector database** and retrieves the most relevant chunks for each question
- 💬 Passes the retrieved context to an **LLM** to generate grounded answers, keeping conversation history

**Stack:** `Python` `LLM` `RAG` `Embeddings` `Vector DB`

[![Repo](https://img.shields.io/badge/📂_View_Repo-00B4D8?style=for-the-badge)](https://github.com/RathanVengala/rag-pdf-chatbot)

### 💊 MediTrack AI — AI Voice Agent for Pharmacy Enquiry & Order Automation
An AI voice agent that answers pharmacy phone calls, handles medicine enquiries and takes orders, grounded in the pharmacy's real formulary and stock. Anything clinical or uncertain is handed to the pharmacist.

`Voice → Speech-to-Text → Intent + Entities → Knowledge Base → Order Workflow → Spoken Reply`

- 📞 Answers real calls via **Twilio voice webhooks**, with **Whisper** speech-to-text and hallucination filtering
- 🔍 **Phonetic medicine search** resolves mis-heard drug names (e.g. "amoxy sillin" → Amoxicillin) with 100% recall on 35 test cases
- 🛒 Takes orders over multiple turns using a deterministic **slot-filling state machine**, with **inventory reservation** so two callers can't buy the same last pack
- 🩺 Routes dosage questions, prescription-only and cold-chain items to a prioritised **pharmacist escalation queue**
- 🔐 Hardened with API-key auth, Twilio signature verification, input limits, file locking and automatic recovery
- ✅ **232/232 tests passing**, plus a 131-case accuracy benchmark

**Stack:** `Python` `FastAPI` `Twilio` `Whisper` `OpenAI / Anthropic LLMs` `REST APIs`

[![Repo](https://img.shields.io/badge/📂_View_Repo-00B4D8?style=for-the-badge)](https://github.com/RathanVengala/medi-track)
